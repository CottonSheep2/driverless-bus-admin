# 无人驾驶公交车运行管理系统 - 前端

基于 Vue 3 + TypeScript + Element Plus 的管理后台前端。

## 技术栈

| 分类 | 技术 | 版本 |
|------|------|------|
| 框架 | Vue 3 (Composition API) | 3.5.x |
| 语言 | TypeScript | 6.0 |
| 构建工具 | Vite | 8.x |
| UI 组件库 | Element Plus | 2.8.x |
| 图标 | @element-plus/icons-vue | 2.3.x |
| 路由 | Vue Router | 4.4.x |
| 状态管理 | Pinia | 2.2.x |
| HTTP 请求 | Axios | 1.7.x |
| 图表 | ECharts | 6.1.x |

## 快速启动

### 环境要求

- Node.js 18+
- npm 或 pnpm

### 安装依赖

```bash
npm install
```

### 开发模式启动

```bash
npm run dev
```

启动后访问 **http://localhost:5173**，Vite 已配置代理将 `/api` 请求转发到后端 `http://127.0.0.1:8080`。

> 启动前端前请确保后端服务（bus-service）已运行，且 MySQL、Redis 均已启动。

### 生产构建

```bash
npm run build
```

构建产物输出到 `dist/` 目录。

## 功能模块说明

### 系统首页 (Dashboard)
- 顶部统计卡片：站点总数、线路总数、公交车总数、待处理告警数
- ECharts 饼图：车辆状态分布（在线/离线/检修/运营中）
- ECharts 柱状图：告警类型统计
- 最近告警列表

### 站点管理
- 分页表格展示站点列表，支持按站点名称搜索
- 新增/编辑站点弹窗表单
- 删除站点（仅管理员）

### 线路管理
- 分页表格展示线路列表
- 新增/编辑线路时可选择并排序途经站点
- 删除线路（仅管理员）

### 公交车管理
- 分页表格展示车辆列表，支持按车牌搜索、按状态筛选
- 新增/编辑车辆弹窗表单（绑定线路）
- 删除车辆（仅管理员）

### 告警管理
- 分页表格展示告警列表，支持按状态筛选
- 上报告警（选择车辆、告警类型、描述）
- 处理告警（填写处理措施）
- 删除告警

### 告警类型管理（仅管理员）
- 告警类型的增删改查

### 用户管理（仅管理员）
- 用户列表、新增/编辑用户、启用/禁用账号、分配角色

### 操作日志（仅管理员可管理）
- 按操作人、模块筛选查询
- 查看请求参数、IP、耗时、执行状态
- 删除单条日志、清空全部日志

### 排班计划管理（运营调度）
- 按线路/方向/状态筛选排班
- 手动新增单条排班（选线路、方向、发车时间）
- 批量生成排班（输入首班、末班、发车间隔，自动生成多条）

### 派车车次任务管理（合并页）
- **派车调度区**（仅管理员可见）：手动派车（待发车排班+空闲车辆）、临时加派（突发客流直接派车）、车辆下线（运营中车辆强制下线，车次标记中断）、线路临时停运（整条线路待发车排班置为停运）、车辆接替（故障车辆由备用待命车辆接替）
- **车次任务区**：分页展示车次（线路、车辆、发车/预计/实际到达、状态），运行中车次可标记完成，查看车次详情（途经站点及到站顺序）

## 权限控制

- **路由守卫**：未登录访问任意页面自动跳转 `/login`
- **菜单控制**：侧边栏根据角色渲染，`SAFETY` 角色看不到告警类型管理、用户管理、操作日志菜单
- **按钮控制**：表格中的新增/编辑/删除按钮根据 `roleCode === 'ADMIN'` 条件渲染
- **后端校验**：即使绕过前端，后端接口也会校验角色，非管理员调用增删改接口返回错误

## 请求封装

`src/utils/request.ts` 基于 Axios：

- 请求拦截：自动从 localStorage 读取 token，注入 `Authorization: Bearer {token}`
- 响应拦截：统一处理错误提示；401 时清除本地登录态并跳转登录页
